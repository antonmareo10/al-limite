Open agentic website

How the agents work, and how their answers are checked

Al límite's agents are published as data, run in your browser on the AI model you choose, and can be used by other agent sites. They answer only from the site's data, and code checks every answer before you read it.

Two agents, seven site actions

  • al_limite_guide finds a body by name, reads its indicator (contracts just under the limit, how many would be expected, the ratio with its 95% interval and its level), lists its contracts with the link to each official record, reads the national figures, the ranking and the method, and can open a body's page behind the chat.
  • caution_check sends the draft to the honesty check and returns it approved (PASS) or corrected (FIX). It is a separate agent so that the check travels with the network when another site runs it.

What code checks in every answer

  • Every figure appears in what Al límite's tools returned for that answer. Rounding a decimal is fine; a count must match exactly. A percentage the model computed, or a figure repeated from memory of an earlier answer, is flagged.
  • Each ratio comes with its 95% interval.
  • An answer about a body's indicator says it is a statistical signal, not proof that any contract was split or that anyone did wrong.
  • No accusatory wording (fraud, corruption, illegal…) outside a negation, and no company names: awardees are letters, as on the rest of the site.

The check runs twice: inside the network, where caution_check calls it on the draft, and in this page, under every answer, whatever the model did. It checks figures, structure and tone, not meaning: a real figure used for the wrong thing within the same answer passes. The code is in site/honesty.js.

Use these agents from your site or your agent

  • Agent sites can run this network in their own page, after their visitor agrees on a consent card: add https://al-limite-agent.vercel.app/al_limite_guide to an agent's tools and https://al-limite-agent.vercel.app to allowed_peers. The six read actions are shared with every site through bridge/; the network runs on your visitor's model and key, never ours.
  • Example: Pide el expediente, a second site on another origin, drafts a request under Spain's transparency law to see a body's contract files, and fills it with the file numbers and official links it gets from these agents.
  • MCP: the same six reads, including check_answer, are a read-only MCP server at https://al-limite-agent.vercel.app/api/mcp (Streamable HTTP, protocol 2025-06-18).
  • Files: agent-manifest.json, al_limite_guide.network.json, links.json. The instructions are public by design.

What they cannot do

  • Name awardees, say whether a given contract was split or broke the law, or give legal advice.
  • Cover bodies that publish only on regional platforms, or contracts outside 2023–2025.
  • Guarantee that a small model follows every step: some skip caution_check. That is why the page checks every answer too.
